### New features

* [#15073](https://github.com/rubocop/rubocop/issues/15073): Add `AllowTrailingComment` option to `Style/DisableCopsWithinSourceCodeDirective`. ([@bbatsov](https://github.com/bbatsov))
* [#9505](https://github.com/rubocop/rubocop/issues/9505): Add `disable-next` directives scoped to the following statement. ([@bbatsov](https://github.com/bbatsov))
* [#15550](https://github.com/rubocop/rubocop/pull/15550): Add `--display-suppressed` option to also report offenses suppressed by directive comments, including their `--` justification in the JSON formatter. ([@bbatsov](https://github.com/bbatsov))
* [#15523](https://github.com/rubocop/rubocop/pull/15523): Add new `Lint/ArgumentMismatch` cop. ([@bbatsov](https://github.com/bbatsov))
* [#15594](https://github.com/rubocop/rubocop/pull/15594): Add new `Lint/SuperArgumentMismatch` cop. ([@bbatsov](https://github.com/bbatsov))
* [#15581](https://github.com/rubocop/rubocop/pull/15581): Add new `Style/TimeNow` cop. ([@Starlexxx](https://github.com/Starlexxx))
* [#15111](https://github.com/rubocop/rubocop/issues/15111): Add `NumberOfEmptyLines` option to `Layout/EmptyLineAfterMagicComment` to configure the minimum number of empty lines required after magic comments. ([@alejofraga](https://github.com/alejofraga))
* [#13037](https://github.com/rubocop/rubocop/issues/13037): Add `--report-unused-todo-entries` to catch rotting todo files. ([@bbatsov](https://github.com/bbatsov))
* [#15559](https://github.com/rubocop/rubocop/pull/15559): Add new `Style/DirectiveScope` cop to flag `disable`/`enable` pairs and disable-only `push`/`pop` scopes that wrap a single statement and can use `disable-next` instead. ([@bbatsov](https://github.com/bbatsov))
* [#15547](https://github.com/rubocop/rubocop/pull/15547): Make `Lint/RedundantCopEnableDirective` flag `# rubocop:pop` directives without a matching `# rubocop:push`. ([@bbatsov](https://github.com/bbatsov))

* [#13941](https://github.com/rubocop/rubocop/issues/13941): Fix false positives for `Lint/UselessConstantScoping` when assigning with `Class.new`, `Module.new`, `Struct.new`, or `Data.define` after `private`. ([@pdobb](https://github.com/pdobb))

* [#15517](https://github.com/rubocop/rubocop/issues/15517): Fix false positives in `Lint/RedundantSafeNavigation` when `InferNonNilReceiver` is enabled and the receiver name is rebound by a nested block (`it` or a shadowed block parameter). ([@koic](https://github.com/koic))
* [#15572](https://github.com/rubocop/rubocop/pull/15572): Fix `RuboCop::Cop::Registry#freeze` to freeze its internal collections, so that registering a lazily loaded cop after the freeze fails fast at the registration site instead of corrupting the registry. ([@koic](https://github.com/koic))

* [#15558](https://github.com/rubocop/rubocop/pull/15558): Fix `--display-suppressed` reporting a `nil` `justification` when the offense is loaded from the result cache. ([@corsonknowles](https://github.com/corsonknowles))
