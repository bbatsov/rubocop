### New features

* [#15895](https://github.com/rubocop/rubocop/pull/15895): Add an MCP tool that explains what cops do. ([@bbatsov](https://github.com/bbatsov))
* [#15700](https://github.com/rubocop/rubocop/pull/15700): Add `--explain COP` to describe what a cop does, how it is configured, and the examples from its documentation. ([@bbatsov](https://github.com/bbatsov))
* [#15699](https://github.com/rubocop/rubocop/pull/15699): Add `--max-offenses-per-cop` to cap how many offenses a single cop reports. ([@bbatsov](https://github.com/bbatsov))
* [#15948](https://github.com/rubocop/rubocop/pull/15948): Let MCP autocorrection apply the corrections of `AutoCorrect: contextual` cops when asked to. ([@bbatsov](https://github.com/bbatsov))
* [#15945](https://github.com/rubocop/rubocop/pull/15945): Let MCP autocorrection preview its changes as a diff. ([@bbatsov](https://github.com/bbatsov))
* [#15915](https://github.com/rubocop/rubocop/pull/15915): Let MCP inspection cap how many offenses each cop reports. ([@bbatsov](https://github.com/bbatsov))
* [#15930](https://github.com/rubocop/rubocop/pull/15930): Let MCP tools choose which cops run and which files they check. ([@bbatsov](https://github.com/bbatsov))
* [#14666](https://github.com/rubocop/rubocop/issues/14666): Make `Lint/UselessAssignment` register an offense for a block-captured variable that is never referenced. ([@IslamElsayed](https://github.com/IslamElsayed))
* [#15695](https://github.com/rubocop/rubocop/pull/15695): Report autocorrection edits in the JSON formatter. ([@bbatsov](https://github.com/bbatsov))
* [#15940](https://github.com/rubocop/rubocop/pull/15940): Report cop errors and warnings per file in `--format json`. ([@bbatsov](https://github.com/bbatsov))
* [#15945](https://github.com/rubocop/rubocop/pull/15945): Report the offenses MCP autocorrection leaves behind. ([@bbatsov](https://github.com/bbatsov))
