### New features

* [#15631](https://github.com/rubocop/rubocop/pull/15631): Add a preview channel for unstable behavior. ([@bbatsov](https://github.com/bbatsov))
* [#15627](https://github.com/rubocop/rubocop/pull/15627): Add a SARIF formatter. ([@bbatsov](https://github.com/bbatsov))
* [#15686](https://github.com/rubocop/rubocop/pull/15686): Add `AllCops: FailLevel`, the configuration equivalent of `--fail-level`. ([@bbatsov](https://github.com/bbatsov))
* [#15650](https://github.com/rubocop/rubocop/pull/15650): Add `AllowedDirectives` option to `Style/DisableCopsWithinSourceCodeDirective`, exempting directive kinds such as generated `rubocop:todo` comments. ([@bbatsov](https://github.com/bbatsov))
* [#15629](https://github.com/rubocop/rubocop/pull/15629): Add `--changed` to inspect only the files git says changed. ([@bbatsov](https://github.com/bbatsov))
* [#15628](https://github.com/rubocop/rubocop/pull/15628): Add `--diff` to preview autocorrection without writing files. ([@bbatsov](https://github.com/bbatsov))
* [#15615](https://github.com/rubocop/rubocop/pull/15615): Add new `Lint/MisplacedMagicComment` cop to flag magic comments in positions where Ruby ignores them. ([@bbatsov](https://github.com/bbatsov))
* [#15600](https://github.com/rubocop/rubocop/pull/15600): Add the `rubocop:enable-next` directive to re-enable cops for the next statement only. ([@bbatsov](https://github.com/bbatsov))
* [#15600](https://github.com/rubocop/rubocop/pull/15600): Add the `rubocop:next` directive, combining `push`-style `+`/`-` arguments with `disable-next`'s statement scope. ([@bbatsov](https://github.com/bbatsov))
* [#15363](https://github.com/rubocop/rubocop/issues/15363): Let a cop's entry in the default configuration carry a `Preview` section with the defaults it is expected to adopt in the next major release, applied under `Preview`. ([@bbatsov](https://github.com/bbatsov))
